Hilfe zu Familiar

Anmeldung

Ich bekomme keinen Code. Schau im Spam-Ordner nach. Ein neuer Code lässt sich nach 60 Sekunden anfordern; es gilt immer der zuletzt gesendete.

Ich habe kein Passwort. Familiar braucht keins: Du meldest dich mit einem Code per E-Mail oder mit Apple an.

Familien und Einladungen

Wie lade ich jemanden ein? Familie antippen › Einladen › „Einladung teilen“. Die Person öffnet den Link oder gibt den Code in der App unter „Mit Code beitreten“ ein. Ein Code gilt 7 Tage.

Wer darf was? Admins legen in den Familien-Einstellungen fest, ob Mitglieder einladen, die Familie bearbeiten, Mitglieder entfernen sowie Aufgaben anlegen, bearbeiten und löschen dürfen. Abhaken dürfen immer alle Zugewiesenen.

Mitteilungen

Ich bekomme keine Mitteilungen. Prüfe in den iOS-Einstellungen › Familiar › Mitteilungen, ob sie erlaubt sind. Live-Anzeigen auf dem Sperrbildschirm lassen sich dort unter „Live-Aktivitäten“ an- und abschalten.

Outlook

„Genehmigung erforderlich“ beim Verbinden. Dein Unternehmen muss Familiar einmal freigeben. Tippe in Familiar unter Profil › Outlook auf „Freigabe bei meiner IT anfragen“ – die Nachricht enthält alles, was deine IT braucht (Infos für IT-Abteilungen).

Ein Termin fehlt. Familiar gleicht etwa alle 15 Minuten ab und zeigt Termine aus den Kalendern, die du unter Profil › Outlook ausgewählt hast.

Konto löschen

Profil › Konto löschen. Was dabei gelöscht wird, steht in der Datenschutzerklärung.
